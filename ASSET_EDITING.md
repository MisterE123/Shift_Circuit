All visible models use PNG textures you can edit. Open `mods/shift_circuit/textures` in your pixel editor. Restart the world after saving, and clear the client media cache only if it still displays an older image.

Model surface images are 128 by 16 pixel atlases, with eight adjacent 16 by 16 swatches. From left to right: dark chassis, steel, pale metal, brass, teal, recess, white, red. Faces map across each swatch, so patterns and details work, rather than merely sampling a single color. Preserve the atlas proportions. You can enlarge by an integer multiple with nearest-neighbor scaling for more detail. Conveyor animation frames share one atlas to keep their appearance consistent.



`asset_textures.lua` is the model-to-texture mapping. Scene-specific floor/checkpoint and transparent-beam textures override that mapping. The mesh files are in `models/`, with an adjacent MTL pointing to their default texture for external editors. For floor/beam previews in an external editor, assign the scene-specific image from the table above.



Each model has explicit flat face normals for hard mechanical edges. The source generator fixes upward surface winding and recomputes normals. In Blender, retain flat shading on hard edges; recalculate outside normals after changing geometry. Export UVs and normals. The game mesh exporter compensates for Luanti's OBJ X-axis import mirroring; preserve its coordinate convention when replacing a model.



The model generator preserves existing `sc_surface_*.png` files. Other generated textures (floor panels, icons, HUD) are regenerated by the art tools: back up manual edits to those before rebuilding assets. Editing PNGs and restarting the world does not require running any generator.



Sound files are mono Ogg Vorbis under `mods/shift_circuit/sounds`. Replace a file using its existing name to customize a sound. `sound_sources.json` records the six ElevenLabs generation IDs and prompts. Runtime event volumes are set in `runtime.lua`.

## Hard-pixel HUD and menu theme



Editable 1x source PNGs are in `art/ui/`, with colors in `palette.json`. The command dock, cards, register numbers, gauges, goal panels, marker, buttons, and menu background use these images. Edit the PNGs, then run `python tools/export_theme.py` to export them using nearest-neighbor integer scaling. This preserves your edits. You may also edit runtime textures directly.



`tools/theme_assets.py` regenerates the default theme from the palette; it overwrites source PNGs, so use the export script for hand-edited art. Runtime card animation uses whole-pixel offsets without fractional zoom. Dynamic descriptions and standard menu labels remain engine text.



The launch pad is `sc_start_marker.png`; pit-edge markings are `sc_pit_edge.png`, applied to narrow `sc_pit_edge.obj` entities generated from actual floor/pit boundaries. The repair pickup has its own model and `sc_surface_pickup_repair.png` atlas, and the repair pad uses `sc_tile_repair.png`. Ghost cone geometry is authored in the same ten-model-units-per-node scale as other assets, with explicit UVs/normals and editable `sc_ghost.png` transparency.





Robot owner marker: `art/ui/sc_your_robot.png`. Priority badges: `art/ui/sc_priority_0.png` through `sc_priority_9.png` and `sc_priority_p.png`. Mounts and part pickups each have `sc_surface_mount_*.png` and `sc_surface_pickup_*.png` atlases. Pit strips use corner-mitered mesh variants to avoid overlapping faces; `tools/edge_assets.py` preserves edited strip art.

Dashboard panels and bars use `art/ui/sc_dashboard_*.png`. Edit these PNGs and export with `tools/export_theme.py`; `tools/dashboard_assets.py` also preserves existing sources. Hover text and layout live in `dashboard_ui.lua`.

Racer rows, status badges, checkpoint counters and camera tools have editable `art/ui/sc_racer_*.png` and `sc_orbit_*.png` sources. `tools/round_assets.py` preserves hand edits; `tools/export_theme.py` exports them at 2x.

Phase sequence: `art/ui/sc_phase_order_0.png` is neutral; `_1` through `_8` highlight the respective phases. Edit these PNGs and run `tools/round_assets.py` to export them while preserving your edits.

Course previews use editable `art/ui/sc_map_*.png` symbols, composed directly from saved tile data. Keep these symbols at their native pixel dimensions: tiles are 8x8, edge walls 8x1 or 1x8. `tools/builder_assets.py` and `tools/export_theme.py` preserve edited sources and export map symbols at 1x. Workshop buttons use `sc_editor_*.png`; course inventory frames use `sc_build_*.png`.

Game-selection icon: `menu/icon.png` (128px), with editable 64px source `art/ui/sc_game_icon.png` and generator `tools/game_icon.py`. ## Shared menu theme and lobby robots

Edit the 32x32 PNGs in `art/ui/menu/` and copy them to `mods/shift_circuit/textures/sc_ui_<name>.png`. The frame, panel, and button images use a 8-pixel nine-slice border, so keep decoration in that border and use a flat center. States are `button`, `hover`, `pressed`, `selected`, `selected_hover`, `selected_pressed`, `primary`, and `danger`. `tools/menu_theme_assets.py` regenerates the defaults (overwriting art edits); `mods/shift_circuit/menu_ui.lua` controls semantic styles and panel placement. Fonts follow the user's Luanti settings for legibility.

Lobby models reuse the same editable `sc_surface_robot*.png` textures as the board robots. `tools/lobby_robot_assets.py` generates feet-aligned `sc_lobby_robot*.obj` meshes from the sixteen board models, retaining UVs and normals. Regenerate them after editing the source models.

## Crate factories

`tools/factory_assets.py` generates the five original factory meshes, their editor icons, directional map icons and status lamp. Edit `sc_surface_factory_loot.png` and `sc_surface_factory_steel.png` in the mod textures folder; all meshes have UVs and face normals. The near-black atlas section is the recessed output interior. Geometry regeneration overwrites these defaults. Factory runtime lamps indicate each outlet independently; red means jammed.

### Client-animated straight conveyors

`mods/shift_circuit/models/sc_tread_straight.b3d` consolidates all slats into one animated mesh. Edit `mods/shift_circuit/textures/sc_surface_conveyor.png` to change the tread appearance. The mesh shares the existing slat atlas and does not embed texture pixels.

Run `python tools/conveyor_animation.py` to regenerate the animated model from `sc_slat.obj`. It exports 12 clipped slat bones with a one-pitch loop over frames 0–24. The server sets animation speed only when the phase or speed changes; clients interpolate the animation. Floor, rails and arrows remain separate editable meshes and textures.

### Mechanical arm and electromagnetic brake

Run `python tools/arm_brake_assets.py` after the base asset generator to rebuild the overhead shoulder, rigid links, gripper palm/fingers and brake models. Each uses its own `sc_surface_*.png` atlas; existing custom atlases are preserved. The brake icon's editable source is `art/ui/sc_part_electromagnetic_brake.png`. Arm pose/timing lives in `mods/shift_circuit/arm_pose.lua`.

Triple Laser and EMP assets are generated by `tools/weapon_assets.py`. Edit their individual `sc_surface_mount_*` and `sc_surface_pickup_*` textures, and the 32px source icons in `art/ui/sc_part_*.png`. The generator preserves existing surface textures.
