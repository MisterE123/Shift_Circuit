`sound_sources.json` identifies every installed audio file, original source filenames, authors, source links, processing, and verification hashes. Original Kenney license notices and the Algate source/license record are in `LICENSES/`. Editable synth recipes and preserved ChipTone base data are in `art/audio/`.

These production credits do not claim that an AI model holds copyright. See `LICENSE-ASSETS.md` for asset scope; original source code and project documentation are MIT-licensed under `LICENSE`.
